\section{Scope}
\label{sec:scope}

The scope of this specialized project is the following:
\begin{itemize}
    \item \textbf{RE activities.} The system covers elicitation, analysis, specification and validation of requirements, and the derivation of a prioritized product backlog for Agile development. Requirements management after delivery (change control, release planning) is out of scope.
    \item \textbf{Input.} A natural-language product idea, optionally with documents uploaded by the project members. Existing code bases or legacy specifications are not used as input.
    \item \textbf{Stakeholders.} Stakeholders are simulated by LLM agents grounded in uploaded documents and in public documents found by search; interviews with real stakeholders are not part of the workflow. A human user supervises the process at review checkpoints.
    \item \textbf{Language.} The output language of the artifacts is a setting of the project; the system has been run with English and Vietnamese output. The evaluation uses English.
    \item \textbf{Research question.} This phase answers RQ1. RQ2, on the stages where human involvement is most valuable, is left to the capstone (thesis) phase.
    \item \textbf{Evaluation.} Scenarios of software products across several domains, without an industrial user study in this phase. \updating{the final set of scenarios and baselines, see Chapter~\ref{chap:evaluation}.}
\end{itemize}
