\section{Report Structure}
\label{sec:report-structure}

This report contains eight chapters:
\begin{itemize}
    \item \textbf{Chapter~\ref{chap:introduction}} introduces the motivation, problem statement, objectives, scope and contributions of the project.
    \item \textbf{Chapter~\ref{chap:background}} presents the theoretical background: requirements engineering, personas, large language models, and LLM-based multi-agent systems.
    \item \textbf{Chapter~\ref{chap:related-work}} reviews related work on LLM-based requirements engineering, stakeholder and persona modeling, and multi-agent coordination, and positions this work against it.
    \item \textbf{Chapter~\ref{chap:proposed-approach}} describes the proposed framework \sysname{}: the agent workflow, the grounded personas, the deliberation mechanisms and the artifact model.
    \item \textbf{Chapter~\ref{chap:system-design}} presents the analysis and design of the system: requirements, use cases, architecture, database and user interface.
    \item \textbf{Chapter~\ref{chap:implementation}} describes the implementation, the technologies used, testing and deployment.
    \item \textbf{Chapter~\ref{chap:evaluation}} presents the plan of the experiments that will answer the research question, a demonstration run of the system, and the threats to the validity of the planned study.
    \item \textbf{Chapter~\ref{chap:conclusion}} summarizes the work, discusses its limitations and outlines the plan for the next phase.
\end{itemize}
