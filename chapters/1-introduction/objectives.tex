\section{Objectives}
\label{sec:objectives}

The goal of this project is to design, build and evaluate an LLM-based multi-agent system that supports the requirements engineering process from an initial product idea to a validated, prioritized product backlog, and to answer RQ1 (Section~\ref{sec:research-questions}). The project pursues the following specific objectives:
\begin{itemize}
    \item To survey LLM-based requirements engineering, LLM-based stakeholder and persona modeling, and multi-agent coordination mechanisms, and to identify the gap between them.
    \item To propose \sysname{}, a persona-driven multi-agent framework that models requirements engineering as a dynamic, non-linear deliberation workflow.
    \item To ground the simulated stakeholder personas in evidence mined from real-world documents of the target domain.
    \item To analyze and design the system following software engineering practice: requirements, use cases, architecture, database and user interface.
    \item To implement the system as a web application with a reusable agent workflow, human review checkpoints and traceability between artifacts.
    \item To evaluate how much multiple stakeholder agents with different perspectives contribute to elicitation and refinement, in terms of requirement coverage, diversity, quality, cost and latency (RQ1).
\end{itemize}
